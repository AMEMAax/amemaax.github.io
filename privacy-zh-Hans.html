ToiLog 由 Misora Yatsuki 开发，帮助您记录和回顾如厕及饮水情况。本文说明 iOS 应用的数据处理方式。

1. 保存与同步

记录保存在设备上，并通过 Firebase Authentication 和 Cloud Firestore 自动进行云端保存与同步，适用于免费版和 Pro。记录的日期、类型、数量、状态、颜色及备注等会与匿名认证 ID 或设备 ID 关联。匿名认证并不意味着记录已被匿名化。iCloud 可用时也会同步主个人档案的记录。通过支持的功能附加的照片文件保留在设备上，应用不会将这些图像发送至 Firebase 或 OpenAI。

2. 发送至 AI 的数据

AI 预测、评论和报告使用 OpenAI API。根据功能需要，会发送记录日期、类型、次数、饮水量、汇总信息、健康档案、咨询问题以及相关记录的详情或备注。预测和评论也可能在使用应用时自动触发发送。请勿在自由文本栏中填写姓名等不必要的个人信息。AI 输出不能替代诊断或治疗。

3. 其他服务

Firebase Analytics 接收页面使用、记录类型和购买操作等使用事件，Crashlytics 接收诊断信息。免费版使用 Google AdMob 展示广告。这些服务可能处理标识符、设备信息及 IP 地址。Apple 处理购买和订阅，应用不会收到银行卡信息。服务提供商可能按照各自政策在您所在国家或地区以外处理数据。

4. 查阅、删除与保存期限

您可以在应用中编辑或删除记录。仅卸载应用不会删除 Firebase、iCloud、服务商日志或备份中的全部数据。如需查阅或删除已保存的记录，请联系下方邮箱。我们可能需要核实信息以确定相关数据。使用和诊断日志的保存遵循服务商的设置与政策，不保证所有数据具有统一的保存期限。

5. HealthKit 及其他政策

经您授权后，HealthKit 集成会读写饮水量并读取步数。来自 HealthKit 的数据不会用于广告。您可以在设备设置中更改权限。本服务不面向 13 岁以下儿童。政策变更时，我们会更新此页面及更新日期。
